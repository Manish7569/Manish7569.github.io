## 🚀 Deploy to GitHub Pages — Step by Step

### Prerequisites

| Tool | Download |
|------|----------|
| Git | https://git-scm.com/downloads |
| GitHub Account | https://github.com/signup (free) |

---

### STEP 1 — Install Git

1. Go to https://git-scm.com/downloads
2. Download and run the installer (click Next through all screens)
3. Verify in terminal: `git --version`

---

### STEP 2 — Configure Git (one time only)

Open **Terminal** (Mac) or **Command Prompt** (Windows) and run:

```bash
git config --global user.name "Manish Reddy"
git config --global user.email "Manishreddy.ai@outlook.com"
```

---

### STEP 3 — Create GitHub Repository

1. Go to https://github.com/new
2. Set:
   - **Repository name:** `my-portfolio`
   - **Visibility:** ✅ Public
   - ❌ Do NOT add README (we have our own)
3. Click **Create repository**
4. Keep the page open — you'll need the URL

---

### STEP 4 — Get the Files on Your Computer

1. Download and extract the ZIP from Claude
2. You should have a folder `my-portfolio/` with these 4 files:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`

---

### STEP 5 — Open Terminal in Your Project Folder

**Windows:**
- Open the `my-portfolio` folder in File Explorer
- Click the address bar → type `cmd` → press Enter

**Mac:**
- Right-click the `my-portfolio` folder → **New Terminal at Folder**

---

### STEP 6 — Push to GitHub (run these commands one by one)

```bash
git init
```

```bash
git add .
```

```bash
git commit -m "Initial portfolio launch"
```

```bash
git branch -M main
```

```bash
git remote add origin https://github.com/Manish7569/New_Portfolio.git
```

```bash
git push -u origin main
```

> **If Git asks for a password** → use a Personal Access Token (see below)

---

### 🔑 Personal Access Token (if needed for git push)

1. Go to https://github.com/settings/tokens
2. Click **Generate new token (classic)**
3. Fill in: description = `portfolio`, expiry = 90 days, check ✅ **repo**
4. Click **Generate token** → copy it immediately
5. When Git asks for your password → paste the token

---

### STEP 7 — Enable GitHub Pages

1. Go to your repo: https://github.com/Manish7569/New_Portfolio
2. Click **Settings** tab → scroll to **Pages** in the left sidebar
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Click **Save**

---

### STEP 8 — Your Portfolio is Live! 🎉

Wait 1–2 minutes, then visit:

```
https://manish7569.github.io/New_Portfolio
```
